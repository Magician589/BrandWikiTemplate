Act as a senior web developer with documentation architecture knowledge and Wikipedia-style editor experience.

I will provide Markdown files from my Brand Wiki. Your job is to create simple html/css/js website for my private Wikipedia-style brand knowledge base, which is allowing me to read the .md files through the frontend website. Keep the .md files structured as they are.   The website is for visual representation of the brand content, for example the .md files information.

Use the Wikipedia Manual of Style/Layout as the structural reference and style guide:

https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style/Layout

Your task:

Create consistent Brand Wiki system.

Follow this format for every page:

# Page Title

> Short description of the page topic in one sentence.

Lead section:

Write 1 to 3 paragraphs summarizing the topic before any detailed sections. The lead should be neutral, factual, and useful.

## Overview

## Background

## Main concept

## Strategic relevance

## Usage

## Related pages

## References

## External links

Rules:

- Use brand specific language

- Be specific and clear

- Keep paragraphs short and focused.

- Use logical heading hierarchy.

- Do not skip heading levels.

- Add internal Markdown links between related files.

- Where information is missing, add `[Citation needed]` or `[To be defined]`.

- Preserve the brand’s meaning, but make the writing cleaner, more structured, and more wiki-like condensed.

- Use tables where an infobox or summary would help.

- Add a “See also” or “Related pages” section near the end.

- Add a “References” section if claims, sources, or strategic documents are mentioned.

- Keep formatting consistent across all Markdown files.

Output:

Brand Wiki page.
